# 홈커밍데이 환영 오프닝: 스토리보드 v1

- 규격: 1920×1080 · 30fps · H.264
- **총 길이 52.367초 (1,571프레임)**: 인트로 7.0초 + 영상 40.367초 + 엔드카드 5.0초 (80초 이하)
- 구성: **남는 시간 39.6초 → A안 (인트로 + 영상 4개 연속 + 엔드카드)**
- 원칙: 영상 4개는 **원본 그대로, 프레임 공백 없이** 이어 붙인다. 디자인은 영상 *위에* 얹고, 오디오는 영상 경계에서 겹치거나 늦어지지 않게 한다.
- 전처리(확정): HDR→SDR(BT.709) 변환본, -16 LUFS 정규화, 가벼운 노이즈 감소, 경계 5ms 마이크로 페이드, 손떨림 보정 없음, 화자 이름은 "나중에 입력"

## 2. 영상 구간 공통 레이어 (0:07.000 – 0:47.367)

```
┌──────────────────────────────── 1920 × 1080 ────────────────────────────────┐
│  [배경] 현재 영상을 크게 확대 + 강한 블러(60px) + 어둡게 + 브랜드 색 틴트        │
│  [그레인 6%] [라이트 리크: 화면 모서리에서 천천히 흐름]                          │
│      ┌──────────────────── 영상 카드 1536×864 (80%) ───────────────────┐       │
│      │ ┌──────────────┐ ← 로우서드 (영상 시작 0.3~3.5초)               │       │
│      │ │ 20기 위원     │                                               │       │
│      │ │ ○○○ (나중에)  │      원본 영상 (Ken Burns 1.00→1.04)          │       │
│      │ └──────────────┘                                                │       │
│      │                                                                 │       │
│      └──────────────── 라운드 32px · 그림자 · 얇은 하이라이트 테두리 ────┘       │
│          ┌──────────── 키네틱 자막 (반투명 잉크 배경 pill) ────────────┐        │
│          │      오늘의  ████20주년████을  만들었습니다                   │        │
│          └─────────────────────────────────────────────────────────────┘        │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **카드**: 화면의 80% 크기, 중앙에서 약간 위(y center 500). 카드 전체는 3~4초 주기로 ±3px 정도 아주 미세하게 떠다님(spring 기반 노이즈).
- **Ken Burns**: 카드 *안의* 영상만 영상마다 1.00→1.04로 서서히 확대. 얼굴 쪽(화면 상단 1/3)을 기준점으로 잡음.
- **블러 배경**: 같은 영상을 배경용으로 한 번 더 깔아 블러 처리. 경계에서는 배경도 함께 바뀌는데, 카드 전환과 라이트 스윕에 묻혀 보이지 않음.
- **자막**: Pretendard Bold 64px, 최대 2줄, 하단 y 920~1040, 잉크 색 72% 배경 pill. 문장 단위로 들어오고, **단어는 말하는 타이밍에 맞춰 순서대로 밝아짐**(미발화 단어 40% → 발화 100%). **핵심 단어**는 포인트 색 + 1.15배 + 위로 튀는 spring.
- **로우서드**: 영상 시작 0.3~3.5초에 카드 좌상단 안쪽에 표시. 포인트 색 바가 먼저 그어지고 텍스트가 마스크로 드러난 뒤 역순으로 사라짐. **문구는 "나중에 입력"이며, 우선 `20기 청소년운영위원`으로 채워 둠.**

### 경계 전환 (전환 방식은 후보 중 선택, 아래 추천안 기준)

- 오디오는 경계 프레임에서 **원본 그대로 이어 붙임**(겹침·지연 없음, 5ms 마이크로 페이드만).
- 화면: 나가는 카드는 **자기 영상의 마지막 0.2초 동안(아직 재생 중)** 밀려 나가고, 들어오는 카드는 **경계 프레임에서 첫 프레임부터 재생하며** 0.3초 동안 들어옴. 전환 전체 길이는 0.5초.
- **정지 화면(프리즈)을 쓰지 않으므로** "멈춤 금지" 규칙을 지킴. 두 카드 사이에 1~2프레임 동안 보이는 것은 검은 화면이 아니라 블러 배경과 라이트 스윕.
