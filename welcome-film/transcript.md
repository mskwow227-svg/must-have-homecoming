# 환영인사 영상 대본 (검수용)

- 받아쓰기: Whisper large-v3 (faster-whisper, 한국어, CPU int8)
- **절대 타임코드**는 영상 4개를 공백 없이 1→2→3→4로 이어 붙였을 때(인트로 제외) 기준입니다.
- 단어 시작 시각은 Whisper 추정치라 ±0.2초 정도 오차가 있습니다. 자막 싱크는 3단계에서 파형 기준으로 다시 맞춥니다.
- 표시 규칙
  - ⚠️**단어** — 잘못 들었을 가능성이 높음. 대괄호 안이 추정 정답. **검수 필요**
  - 🔎**단어** — 인식 신뢰도가 낮음(맞을 가능성은 높지만 확인 부탁)
  - `(무음)` — -42dB 이하 구간(말 없음, 손 흔들기 등)
